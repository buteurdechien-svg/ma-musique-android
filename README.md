# Ma Musique — Android

Lecteur de musique personnel (Kotlin + Jetpack Compose + Media3), style Apple Music.

- **Accueil** : écoutés récemment, ajoutés récemment, favoris, les plus écoutés
- **Bibliothèque** : playlists, artistes, albums, morceaux, favoris
- **Recherche** : tuiles colorées + recherche dans les titres, artistes et albums
- **Lecteur** : lecture en arrière-plan, notification et écran de verrouillage, aléatoire, répétition, file d'attente
- **Navigateur intégré** : télécharge les MP3 depuis ton Drive ou ton site directement dans `Musique/MaMusique`

## Récupérer l'APK
Chaque push sur `main` lance l'onglet **Actions** → « Construire l'APK ». L'APK est dans les *Artifacts* du build.
